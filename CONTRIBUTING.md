# Přispívání

1. Úpravy provádějte v `src/`; vygenerované `docs/index.html` neupravujte.
2. Datovou logiku držte v `src/core/`, práci s DOM v příslušné části `src/features/`.
3. Přidejte věcný test pro změnu datového chování; nepoužívejte živé statistické
   soubory v automatických testech.
4. Před odesláním spusťte `npm run format` a `npm run check`.
5. Změnu vysvětlete v pull requestu, včetně toho, jak byla ověřena.

Podrobný postup a popis sestavení jsou v [dokumentaci vývoje](documentation/development.md).
