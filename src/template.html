Připravuji data

Požadavky řadíme do šetrné fronty. Již uložené soubory zůstávají v cache.

Místní data

Data jsou uložená v tomto prohlížeči. Smazané soubory lze znovu načíst.

Požadavky a ochrana API

Nejvýše jeden souběžný požadavek, odstup alespoň 1,2 s a nejvýše 30 požadavků za minutu. Server může vyžadovat delší přestávku.

429 a Retry-After pozastaví frontu. Chyby 403 přístup dočasně zastaví; vybrané dočasné chyby opakujeme nejvýše dvakrát. Sdílení limitu mezi kartami využívá Web Locks a místní úložiště, pokud je prohlížeč zpřístupní. Viditelnost hlaviček řídí CORS poskytovatele.

O aplikaci

Uložit graf jako obrázek

Název, výřez, jednotka a zdroj budou součástí obrázku.

Otevřít vlastní soubor

Soubor se zpracuje pouze zde. Podporujeme CSV, JSON-stat a ploché JSON záznamy do 20 MB.

Není vybrán soubor

Každá kombinace kategorií musí být jednoznačná. Duplicitní řádky automaticky nesčítáme.
